## Descripción del Proyecto
Sitio web de una sola página (`index.html`) que funciona como un Perfil Profesional Interactivo. Diseñado de forma responsive y utilizando únicamente tecnologías nativas sin librerías externas.

---

## Tecnologías Utilizadas
* **HTML5 Semántico:** Estructuración limpia utilizando etiquetas semánticas (`<header>`, `<main>`, `<section>`, `<article>`, `<blockquote`).
* **CSS3:** Diseño con variables CSS, CSS Grid, Flexbox, diseño responsive (Mobile First), sombras y efectos hover.
* **JavaScript Nativo (ES6+):** 
  * Alternancia de modo claro / modo oscuro.
  * Contador de visitas dinámico persistiéndose mediante `localStorage`.
  * Fecha y hora actualizadas en tiempo real.
  * Ventana modal interactiva para detalles de proyectos.
  * Validación completa de formulario de contacto.
* **Git & GitHub:** Control de versiones con trabajo exclusivo sobre la rama asignada (`cgarciaf11`).
