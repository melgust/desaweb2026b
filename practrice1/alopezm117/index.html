01 Sobre mí

Me apasiona la tecnología y el desarrollo de software, y disfruto aprender de forma continua: cada proyecto es una oportunidad para encontrar una mejor manera de resolver un problema. 03 Proyectos

Nube de Tareas

Aplicación web para la gestión y organización de tareas, que permite crear, editar y administrar actividades de manera sencilla para mejorar la productividad.

Tecnologías: HTML5, CSS3, JavaScript (localStorage)

Funcionalidades clave: crear, editar, marcar como completada y eliminar tareas, con persistencia de datos en el navegador.

Aprendizaje: manejo del DOM y almacenamiento local para conservar información entre sesiones.

DB Link

Sistema desarrollado para la administración de información utilizando bases de datos relacionales, implementando operaciones CRUD y consultas SQL para el manejo eficiente de los datos.

Tecnologías: SQL, modelado relacional, operaciones CRUD

Funcionalidades clave: creación de tablas, relaciones entre entidades, consultas para filtrar y actualizar registros.

Aprendizaje: diseño de bases de datos normalizadas y optimización de consultas.

Amigo Secreto

Aplicación web que automatiza el sorteo de "Amigo Secreto", permitiendo registrar participantes y generar asignaciones aleatorias de forma rápida y sencilla.

Tecnologías: HTML5, CSS3, JavaScript

Funcionalidades clave: registro dinámico de participantes y sorteo aleatorio sin repetir asignaciones.

Aprendizaje: manipulación de arreglos y lógica de aleatorización en JavaScript.
