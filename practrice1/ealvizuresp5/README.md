# Perfil Profesional Interactivo

Práctica 1 del curso de Desarrollo Web.

## Descripción

Este proyecto consiste en una página web de perfil profesional desarrollada con HTML5, CSS3 y JavaScript.

La página incluye información personal, habilidades, proyectos académicos y un formulario de contacto con validación.

## Funcionalidades

- Cambio entre modo claro y modo oscuro.
- Fecha y hora actualizadas automáticamente.
- Contador de visitas guardado en el navegador.
- Información adicional de los proyectos mediante una ventana modal.
- Validación del formulario de contacto.
- Diseño adaptable para computadoras, tabletas y teléfonos.
